## 3. 常驻资源实测

测量工具：`scripts/measure_footprint.c` → `proc_pid_rusage` 的 `ri_phys_footprint`（**与 macOS 活动监视器「内存」列同口径**）；RSS 取自 `proc_taskinfo`。

```bash
cc -O2 -o /tmp/footprint scripts/measure_footprint.c
/tmp/footprint <pid>
```

| 场景 | 活动监视器「内存」 | RSS | 说明 |
| --- | --- | --- | --- |
| `--hidden` 启动（开机自启态） | **≈ 15 MB**（多次测量 12.5–14.8 MB） | ≈ 70 MB | 桌面端主窗口 `create:false`，进程内**从未创建 WebView**，无 WebKit 日志/子进程 |
| 打开主窗口 | **≈ 31 MB**（26.7–31.4 MB） | ≈ 103 MB | 含 WKWebView |
| 使用后关闭窗口（关闭到托盘） | **≈ 26 MB** | ≈ 97 MB | 窗口被销毁（Tauri `webview_windows()=0`）；WebKit 框架页常驻约 11 MB，无法卸载 |

CPU / 网络：

- 进程启动后 5 秒累计 CPU 时间 **0.008 秒**（≈ 0%，同值重复采样无增长）→ 无定时器、无轮询；
- 托盘空闲时无任何网络请求（HTTP 客户端空转，`pool_idle_timeout=90s`）；
- 无 WebView 子进程（托盘态 `WebKit` 相关日志计数 = 0）。

> 与 Electron 方案（托盘态常见 120–250 MB）相比，常驻内存降低一个数量级；这是选择 Tauri 的核心理由。

## 4. 窗口生命周期验证

| 验证项 | 方法 | 结果 |
| --- | --- | --- |
| 关窗 → 销毁窗口 → 驻留托盘 | `hulian --close-after 5`；2s / 8s 两次采样窗口列表与内存 | 8s 时 780×640 主窗口 `onscreen=-1`（不在屏幕），日志 `CloseRequested → destroy ok`，进程继续驻留 |
| 按需重建窗口 | 窗口销毁后启动第二个实例（单实例插件回调 → `show_main_window`） | 3 秒后 **新的 780×640 窗口重新出现（onscreen=1）**，前端重新加载并拉取全量状态 |
| 关闭窗口时「直接退出」模式 | 代码路径：`closeToTray=false` → 不拦截关窗 → `ExitRequested` 放行 | 已按此逻辑实现（真机点击关窗操作未自动化，逻辑与 `--close-after` 同一事件路径） |
| Cmd+Q / 托盘退出 | macOS 自定义菜单 + 托盘菜单 → `quitting=true` → `app.exit(0)` | 逻辑实现；`--import-cli`/`--selftest` 均通过 `app.exit(0)` 正常退出（exit code 0） |

## 6. 已知限制（发布时如实说明）

1. **无云端删除**：当前 API Key 对 `POST /v2/file/delete`、回收站清空返回 `403 Forbidden / CheckRouterAccessFailed`（API Key 权限限制）；App 只提供「云端可见 + 下载」。
2. **签名/公证**：macOS 产物未签名、未公证，首次打开需右键 → 打开，或 `xattr -cr "互联.app"`。
3. **Windows / Android 未实机验证**：源码、构建脚本（`scripts/build-windows.ps1`、`scripts/build-android.sh`）与 GitHub Actions（`.github/workflows/build.yml`）已就绪。
   - 2026-10-21 GitHub Actions 首次运行：macOS ✅（dmg）、Windows ✅（`互联_0.1.0_x64-setup.exe` 2.2 MB，已上传 Release）、Android ❌（`android-actions/setup-android@v3` 与 runner 的 cmdline-tools 兼容问题，已修复 workflow 等待复跑）。
   - 本机无 Windows / JDK+NDK 环境，因此 Windows / Android 产物未在本机产出，也尚未在真机上安装运行验证。
4. **Android 上传为 SAF 复制方案**：系统选择器返回 `content://`，经 `tauri-plugin-fs` 读成缓存副本再上传（大文件会占用一份缓存空间），未真机验证。
5. **token 明文保存在本地配置文件**（权限 0600），未接入系统钥匙串（见 README 路线图）。
6. 云端测试残留：根目录 `_测试残留（可删除）/` 可整体删除（App 无删除权限）。
