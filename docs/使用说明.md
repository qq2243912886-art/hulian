## 安装

### macOS

1. 打开 `互联_0.1.0_aarch64.dmg`，把「互联」拖进「应用程序」。
2. 首次打开：未签名 App 会被 Gatekeeper 拦截。在「应用程序」里**右键 → 打开 → 打开**；或执行：

   ```bash
   xattr -cr "/Applications/互联.app"
   ```

3. 首次上传/下载时，系统可能询问"访问下载文件夹"等权限，请允许（或之后到「系统设置 → 隐私与安全性」补充授权）。

> Intel Mac：构建产物名可能为 `互联_0.1.0_x64.dmg`；本仓库默认在 Apple Silicon 上构建 arm64。

### Windows

1. 运行 `互联_0.1.0_x64-setup.exe`，按提示安装。
2. 若出现 SmartScreen 提示，选择「更多信息 → 仍要运行」（未签名安装包的正常现象）。
3. 依赖 **WebView2 运行时**：Windows 10 1803+ / Windows 11 通常已自带；若启动白屏，请安装 Microsoft Edge WebView2 Evergreen 运行时后重开。

### Android

1. 把 `app-universal-debug.apk` 传到手机，点击安装（需允许「安装未知来源应用」）。
2. 这是 **debug 签名**的测试包，不是应用商店分发版本；安装时可能提示风险，确认即可。
3. 手机端没有托盘和开机自启，传输时请保持 App 运行；上传使用系统文件选择器（选中文件会先复制到 App 缓存再上传，未真机验证）。

## 先搞清楚：数据存在哪里

「互联」没有自有服务器。你上传的文件会出现在**你自己的阿里云盘**里：

```text
阿里云盘
└── 根目录
    └── 文件互传            ← 默认名；可在设置里改；首次使用时自动创建
        ├── 你的文件 A.pdf
        ├── 你的文件 B.zip
        └── ...
```

- 云端目录固定一个，所有设备看到的是同一个目录；
- 上传同名文件时云端**不会覆盖**，会自动改名（例如追加时间或序号，取决于云盘行为），原文件保留；
- 在阿里云盘 App / 网页里也能直接看到、下载、管理这些文件；**删除请到阿里云盘 App / 网页操作**（原因见 [已知限制](#已知限制)）。

本地文件：

- 下载默认保存到本机下载目录下的「互联」文件夹（可改，见 [设置项说明](#设置项说明)）；
- 上传只读取你选中的文件，不复制、不搬移、不改名。

## 获取访问令牌（token）

「互联」使用**阿里云盘的 API Key**（`uk-` 开头，产品文案里也叫「个人访问令牌」）访问你的云盘。获取方式三选一：

> 说明：`uk-` 是阿里云盘的**静态长效凭据**（API Key），不是会过期的 OAuth 登录令牌；创建时需设置过期时间，没有自动刷新机制。完整调研见 [PDS-API 调研报告 · 认证](PDS-API调研报告.md#1-认证)。

### 方式 A：本机装过 aliyun CLI（桌面端一键导入，推荐）

如果你的 Mac / Windows 上安装过 `aliyun` CLI 并配置过 `aliyun pds` 插件，凭据通常在：

```text
~/.aliyun/pds_config.json          # macOS / Linux
%USERPROFILE%\.aliyun\pds_config.json   # Windows
```

文件里有 `profiles[0].access_token`（`uk-...`）、`endpoint`、`domain_id`、`drive_id`。
打开「互联 → 设置 → 账号」，点击 **「从本机 aliyun CLI 导入」**，App 会自动读取当前 profile（`current`，没有则取第一个）并填入 endpoint、domainId 与 token（`uk-` 开头），无需手动复制。

> 说明：本机 aliyun CLI 的配置里 `authentication_type = api_key`、`refresh_token` 为空，`access_token` 就是 `uk-` API Key。API Key 静态长效但**创建时会设定过期时间**（每个用户最多 2 个）；到期或失效时需在控制台改期/新建，再更新到各设备。

### 方式 B：手动创建令牌（没有 CLI 时）

在**阿里云盘网页控制台**（企业文件管理：`https://www.aliyunfile.com`）的「API Key」页面新建一个 API Key（`uk-` 开头），复制备用。创建时需要选择过期时间；入口以你账号所属版本的控制台为准（详见 [PDS-API 调研报告 · 认证](PDS-API调研报告.md#1-认证)）。

### 方式 C：复用已有配置文件

如果 CLI 已配置好但不想让 App 读取整个配置，也可以手动打开上面那个 JSON，只复制 `profiles[0].access_token` 的值，粘贴到 App 设置页。

> ⚠️ token 等价于你云盘账号的访问权限：不要发到聊天群、不要截图、不要提交到 git（项目 `.gitignore` 已排除常见敏感文件）。怀疑泄露时，到控制台重新生成令牌，并在所有设备上更新。

## 首次配置 · 桌面端

1. 打开「互联」。
2. 首次启动会进入欢迎引导（未配置账号时）。点「配置账号」。
3. 账号信息二选一填写：
   - **一键导入**（方式 A，全自动）：
     - 自动读取 `~/.aliyun/pds_config.json`，回填 endpoint / domainId / token；
     - 自动请求云盘校验账号，并**默认选择第一个空间**回填 `driveId` / 空间名（多空间账号可在设置里修改）；
     - 点击「测试连接」，看到用户名、空间名与容量即成功。
   - **手动填写**（方式 B / C）：

     | 字段 | 填什么 | 本机示例 |
     | --- | --- | --- |
     | endpoint | API 域名（不带路径） | `bjxxxxx.api.aliyunfile.com` |
     | domainId | 域名前缀里的域 ID | `bjxxxxx` |
     | driveId | 空间 ID | `2` |
     | token | 个人访问令牌 | `uk-xxxxxxxx...` |

4. 点击「保存并测试」。提示「连接正常」后即可使用。
5. 建议顺手设置：设备名（区分多台设备的传输记录）、云端互传目录名、下载目录、分片大小与并发（默认值通常够用）。

> 换账号 / token 失效时，回到「设置 → 账号」更新后重新测试连接即可；进行中的传输不会自动迁移到新账号。

## 首次配置 · 手机端

手机上没有 `~/.aliyun/pds_config.json`，**不能一键导入**，需要手动粘贴：

1. 在电脑上用方式 A/B 拿到 token，复制。
2. 通过微信/文件传输/AirDrop 等任意方式把 token 发到手机（仅作为文本复制，注意不要留在聊天记录里）。
3. 打开手机端「互联 → 设置 → 账号」，填写与电脑端**完全一致**的：

   ```text
   endpoint: bjxxxxx.api.aliyunfile.com
   domainId: bjxxxxx
   driveId:  2
   token:    uk-xxxxxxxx...
   ```

4. 点「测试连接」。成功后，手机与电脑看到的是同一个云端「文件互传」目录。

注意事项：

- Android 端没有托盘/自启；系统可能在省电时杀掉后台，传输请保持 App 在前台。
- 手机端下载位置为 App 可写的下载目录，具体路径在「设置 → 下载位置」中显示；不同 Android 版本可能需要在系统「文件」App 中查看。
- 手机端不需要也不能使用「从本机 aliyun CLI 导入」。

## 多设备与换设备

- **可以多台设备共用同一个 token**：同一阿里云盘账号、同一 `drive_id`，看到的就是同一个互传目录。两台设备同时上传/下载不冲突（同名上传由云端自动改名）。
- **换设备**：在新设备上按「首次配置」粘贴同一套 endpoint / domainId / driveId / token 即可，不需要"配对"或"登录"。
- **建议**：给每台设备起不同的「设备名」（如 `MacBook · 演示用户`、`Pixel · 随身`），便于在传输记录里区分来源。
- **令牌轮换**：如果你在控制台重新生成了 token，旧 token 会失效；需要在**每台设备**的设置里更新，否则会报认证失败。

## 上传文件

入口：主界面「上传」页。

> 当前版本：桌面端上传可用；Android 端上传已实现（系统文件选择器 → 缓存副本 → 上传），**尚未真机验证**，有问题请反馈。

- **桌面端**：
  - 点「选择文件」打开系统文件选择器（可多选）；
  - 或直接把文件/文件夹里的文件拖进窗口；
  - 选中后立即进入传输队列，按分片上传（默认 8MB/片；单文件分片默认串行——官方要求串行以保证服务端 SHA1 校验，可在设置中调高，但属于实验项）。
- **手机端**：点「选择文件」，从系统文件选择器中选一个或多个文件。选中文件会先经 `tauri-plugin-fs` 复制到 App 缓存目录 `picked-files/`，再交给上传引擎（缓存副本可被系统清理；上传成功后不再需要它）。

上传过程中可以看到：文件名、大小、已上传字节、进度条、速度；支持**取消**与失败后的**重试**。

- 云端目标固定是「文件互传」目录；目录不存在时 App 会自动创建（首次使用时自动完成，无需手动建目录）。
- 同名文件**不会覆盖**，云端会自动改名。
- 上传完成前请勿退出 App：桌面端开启「关闭窗口时驻留托盘」时关窗任务会继续；关闭该设置后关窗 / Cmd+W 会直接退出并中断任务。
- 上传完成后去「下载」页刷新，即可看到刚上传的文件（App **不会自动刷新**，避免后台轮询）。

## 下载文件

入口：主界面「下载」页（云端「文件互传」目录的文件列表）。

1. 首次进入或需要最新状态时，点右上角**刷新**按钮。
2. 列表展示：文件名、类型色块、大小、创建时间；支持**多选**后批量下载。
3. 下载中支持取消；失败后点**重试**会从已下载字节处断点续传（同一次 App 运行内有效）。
4. 下载完成后，在传输记录里可以「打开文件」或「在文件夹中显示」；也可以点「打开下载目录」。

说明：

- App 不做云端删除、重命名、移动；这些操作请到阿里云盘 App / 网页完成。
- App 不提供分享链接；需要分享时请使用阿里云盘自带能力。
- 下载 URL 由云盘临时签发（默认 900 秒），过期会自动重新签发；不需要你处理。

## 传输记录

「传输记录」页展示进行中与最近完成的任务：

| 状态 | 含义 | 可执行 |
| --- | --- | --- |
| 排队中 | 等待并发槽位 | 取消 |
| 传输中 | 正在上传/下载，显示进度与速度 | 取消 |
| 已完成 | 传输成功 | 打开文件 / 在文件夹中显示 / 移除 |
| 失败 | 网络或云盘错误，带原因 | 重试 / 移除 |
| 已取消 | 被你取消 | 重试 / 移除 |

- 「清空已完成」只清记录，不动本地文件。
- 传输**队列与进行中任务只在内存**：退出 App 即中断，不跨重启续传；**已结束的记录**（最多 100 条）会保存在本机 `transfers.json`，重开 App 仍能看到历史（实现轻量，不引入数据库）。

## 托盘、窗口与开机自启

> 仅桌面端（macOS / Windows）；Android 没有托盘与自启。

- **关闭窗口的两种行为**（设置项「关闭窗口时驻留托盘」）：
  - **开启（默认）**：点窗口红灯 / Cmd+W → 窗口被销毁、只留系统托盘，空闲开销接近零；正在进行的传输由后台进程继续执行。
  - **关闭**：点窗口红灯 / Cmd+W → **直接退出应用**，进行中的传输会中断。
- **彻底退出**：Cmd+Q、托盘菜单「退出互联」在任何设置下都会真正退出（macOS 使用 App 自定义菜单，Cmd+Q 不会被托盘逻辑拦下）。
- **macOS 托盘态**：窗口销毁后 Dock 不再显示图标，只保留顶部菜单栏托盘图标；点击托盘重新打开窗口后恢复。
- **重新打开**：左键单击托盘图标即可显示/隐藏主窗口（隐藏 = 销毁窗口）；窗口重建后会恢复当前传输列表。
- **托盘菜单**（实际以代码 `tray.rs` 为准）：
  - 打开主界面
  - 快速上传…（Rust 端直接弹选择器并开始上传，然后自动打开窗口）
  - 打开下载文件夹
  - 退出互联
- **菜单快捷键（macOS）**：「互联 → 退出互联」= Cmd+Q；「窗口 → 关闭窗口」= Cmd+W；「编辑」菜单保留 Cmd+C / V / A 等。
- **开机自启**：设置 → 通用 → 开机自启（桌面端可选）。开启后登录系统时以 `--hidden` 启动；若同时开启「关闭窗口时驻留托盘」，启动时不弹窗、直接驻留托盘。关闭后不写系统自启项。
- **单实例**：重复启动「互联」不会开出第二个托盘图标，只会唤起已有窗口。

## 设置项说明

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| 账号（endpoint / domainId / driveId / token） | 连接哪个阿里云盘；桌面端支持一键导入 CLI 配置 | 未配置 |
| 云端互传目录名 | 云盘根目录下的互传目录，首次使用时自动创建 | `文件互传` |
| 下载位置 | 本地下载目录；为空时使用系统默认（下载目录下的「互联」） | 系统默认 |
| 分片大小 | 上传分片大小（MB，1–64）；网络差可调小；超大文件会自动放大分片以控制分片数 | 桌面 8 / 手机 4 |
| 分片并发数 | 单个文件同时上传的分片数（1–4）；默认 1（串行最稳）；官方要求串行，调高属于实验项，可能失败 | 1 |
| 任务并发数 | 同时进行的上传/下载任务数（设置页可选 1–4，后端上限 1–6） | 2 |
| 开机自启 | 登录系统时自动启动（桌面端） | 关 |
| 关闭窗口时驻留托盘 | 开启：关窗销毁窗口、托盘常驻；关闭：关窗 / Cmd+W 直接退出应用（Cmd+Q 始终退出） | 开 |
| 设备名 | 传输记录中标注本机来源 | 系统设备名 |
| 主题 | 深色 / 浅色 / 跟随系统 | 深色 |

> 修改分片大小 / 并发数只影响后续新任务，不会重排正在进行的任务；修改任务并发会重建并发信号量。

## 数据与隐私

- **文件流向**：本机 ⇄ 你自己的阿里云盘。App 没有开发者服务器，也不经过任何第三方中转；上传走 OSS 预签名直传，下载走临时签名 URL。
- **令牌保存**：token 只保存在本机配置文件（系统应用配置目录，桌面端通常为 `~/Library/Application Support/app.hulian.transfer/config.json` 或 `%APPDATA%\app.hulian.transfer\config.json`），不上传、不写日志；Unix 下配置文件权限会收紧为 `0600`。当前版本为明文保存，尚未接入系统钥匙串（路线图）。
- **无遥测**：没有统计、埋点、崩溃上报、广告。
- **网络请求**：只在你操作时发生（测试连接、上传、下载、刷新列表），空闲时没有后台请求与定时任务。
- **云端删除**：App 不提供（当前 API Key 无删除权限）。需要删除时请到阿里云盘 App / 网页操作。
- **本机数据**：除配置外，还会在配置目录写一个 `transfers.json`（最近 100 条已结束传输记录），含文件名与本地路径，不含文件内容与 token。Android 端上传时选中的文件会先复制到 App 缓存目录 `picked-files/`（供上传引擎读取，可被系统清理）。
- **卸载**：桌面端删除 App 即卸载；配置、token 与传输记录会留在系统配置目录，需要彻底清理时手动删除上述目录。手机端在系统设置中卸载 App 会一并清除应用私有数据。

## 常见问题

**Q1：提示"连接失败 / 401 / 认证失败"？**
token 失效或填错。到阿里云盘网页控制台的「API Key」页面改期或新建一个 Key，在设置里更新后点「测试连接」。同时确认 endpoint、domainId、driveId 与 token 属于同一个账号（例如 `bjxxxxx` + `2`）。

**Q2：为什么 App 里不能删除云端文件？**
当前 API Key 调用删除/回收站接口返回 `403 Forbidden（CheckRouterAccessFailed）`，这是凭据权限限制，不是 App 的 bug。请到阿里云盘 App / 网页删除。详见 [PDS-API 契约 · 受限接口](PDS-API契约.md#受限接口删除与回收站)。

**Q3：上传/下载失败怎么办？**
先点重试（下载会断点续传）；仍失败时检查网络、代理/VPN、云盘容量与 token 是否仍有效。弱网下可把分片大小调小后重新上传。

**Q4：上传完成后在「下载」页看不到？**
App 无后台轮询，点一下「刷新」即可。若刷新后仍看不到，请到阿里云盘 App 里确认文件是否落在「文件互传」目录。

**Q5：两个设备上传同名文件会覆盖吗？**
不会。云端使用自动改名策略，同名文件会生成新名字（可能带时间戳/序号），两份都保留。

**Q6：常驻时占多少内存/会不会费电？**
macOS 实测（0.1.0）：托盘常驻约 **15 MB**（活动监视器「内存」口径；用过后关窗约 26 MB），窗口打开约 31 MB；空闲 CPU ≈ 0%，无定时器、无轮询、无网络请求。关闭窗口会销毁窗口与 WebView。Windows/Linux 使用系统 WebView2，结构相同但未在本机实测。详见 [实测与验证报告](实测与验证报告.md)。

**Q7：关闭窗口后传输会停吗？**
取决于「关闭窗口时驻留托盘」设置：开启（默认）时关窗只销毁窗口，传输由后台进程继续；关闭时关窗 / Cmd+W 会退出应用并中断任务。Cmd+Q 与托盘「退出互联」在任何设置下都会中断。手机端请保持 App 运行（系统省电策略可能杀后台）。

**Q8：App 重启后还能续传吗？**
不能跨重启续传：进行中/排队任务只存在内存中，App 退出即中断；已结束的记录会保留（最近 100 条，仅作历史展示，不能恢复成任务）。这是 "轻量" 的取舍，见 [路线图](../README.md#路线图)。

**Q9：能同步文件夹/自动上传吗？**
不能，也不计划在 0.1.x 做。互联只做手动互传，不监听目录、不扫描文件、不后台轮询。

**Q10：支持 iPhone / iPad 吗？**
暂不支持。当前只做了 Android 端，iOS 未适配。

**Q11：开启代理/VPN 后连不上？**
请确认代理为系统全局代理或允许「互联」直连；App 使用 Rust 原生网络栈，不读取浏览器代理设置。

**Q12：下载的文件在哪里？手机上下载后找不到？**
桌面端在设置/传输记录中可「打开下载目录」；Android 下载位置在「设置 → 下载位置」显示，可到系统「文件」App 对应目录查看。具体路径受 Android 分区存储策略影响（未在本机真机验证）。

**Q13：token 泄露了怎么办？**
立即到阿里云盘网页控制台的「API Key」页面改期或新建（旧 Key 可作废），然后在每台设备的设置里更新。

**Q14：怎么自检/排障？**
桌面端有内置命令行入口（在终端运行）：

```bash
# 真实上传→下载→字节比对，成功输出 SELFTEST_UPLOAD_DOWNLOAD OK 后退出
"/Applications/互联.app/Contents/MacOS/互联" --selftest

# 从本机 aliyun CLI 配置导入 API Key 后退出（首次配置/排障）
"/Applications/互联.app/Contents/MacOS/互联" --import-cli
```

Windows 把路径换成安装目录下的 `互联.exe`。详细说明见 [构建与发布 · 诊断与命令行入口](构建与发布.md#诊断与命令行入口)。

## 已知限制

- **无云端删除 / 回收站**：当前 API Key 权限受限（403），删文件请用阿里云盘 App / 网页。
- **无同步、无后台轮询、无目录扫描**：只有手动操作才联网。
- **单账号、单互传目录**：一个设备只连一个账号与一个目录。
- **进行中任务不持久化**：App 退出即中断，不跨重启续传；已结束记录保留最近 100 条（仅展示）。下载断点续传仅同一运行内有效。
- **Android 无托盘、无自启**；传输依赖 App 进程存活。
- **Windows / Android 未在本机实机验证**：构建流程与 CI 已就绪，遇到问题请反馈。
- **Android 尚未真机验证**：上传（系统文件选择器 → `tauri-plugin-fs` 读取 content URI → 复制到 App 缓存 `picked-files/` → 上传）与下载都已实现，但未在真机验证；iOS 未适配。
- **未签名分发**：macOS 需右键打开 / `xattr -cr`；Windows 可能有 SmartScreen 提示；Android 为 debug 签名 APK。
